# Complete Node.js Course

A comprehensive learning journey into backend development with **Node.js**, covering everything from core concepts and server-side applications to REST APIs, GraphQL, databases, authentication, real-time applications, testing, and deployment.

This repository contains my notes, exercises, code examples, and projects developed throughout the course.

## About the Course

The goal of this course is to develop a solid understanding of Node.js and its ecosystem through a combination of theoretical explanations and hands-on development.

Rather than focusing exclusively on isolated examples, the course uses two major projects — an **online shop** and a **blog** — to demonstrate how Node.js concepts and technologies are applied in real-world applications.
